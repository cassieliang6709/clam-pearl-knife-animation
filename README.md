# 河蚌、珍珠和小刀

一组从插画延伸出的短动画与 Three.js 交互作品。

**[打开交互演示](https://cassieliang6709.github.io/clam-pearl-knife-animation/)**

演示中，小刀轻敲闭合的河蚌，贝壳沿左侧铰合点像翻书一样打开，露出珍珠。可以暂停、重播和拖动进度条。Three.js 场景由代码实时生成，运行时不依赖图片帧或视频。

## 本地运行

下载仓库后直接用浏览器打开 `index.html`，无需联网或安装依赖。`bundle.js` 是可直接运行的打包文件；`main.js` 是便于阅读和修改的源代码。
